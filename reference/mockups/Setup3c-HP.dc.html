Aktifkan USB debugging di HP

HP terdeteksi lewat USB, tapi Windows belum melihat antarmuka ADB-nya.
  1. Settings › About phone, ketuk OS version 7 kali sampai muncul pesan developer.
  2. Buka Settings › Additional settings › Developer options.
  3. Nyalakan USB debugging.
  4. Khusus Xiaomi: nyalakan juga USB debugging (Security settings) agar HP bisa dikontrol. Butuh data seluler dan akun Xiaomi.
  5. Tekan Allow pada popup di HP, centang Always allow.
